# Hapa Living Resume

[Open the live GitHub Pages demo](https://calderwong.github.io/hapa-living-resume/)

Hapa Living Resume is a public prototype that combines a living résumé, portfolio, Skill Codex, Proof Map, Hapa ecosystem timeline, and an agent-readable discovery surface. The live demo is based on Calder Wong: his professional experience, public Hapa work, and the knowledge-to-practice loop behind them. It is designed for people—recruiters, collaborators, and hiring teams—while also giving search and recruiting agents structured, source-aware paths through the same story.

The larger purpose is a reusable scaffold for agent-readable professional context. An agent should be able to understand not only what a person has done, but the knowledge that informed the work, the decisions and patterns that emerged, the evidence behind claims, and how those capabilities were applied in practice. Calder’s site is the first working example, not a claim that every person’s story can be inferred automatically.

## Why it exists

Traditional résumés flatten a person’s work into a short, static document. This project explores a more useful alternative: a navigable, evidence-aware profile that can show experience, the knowledge that informed it, the reusable patterns mined from it, and the prototypes that carry those patterns forward.

It also demonstrates the Hapa method: capture human-agent work, attach it to knowledge and results, compress repeatable learning into Cards and skills, and reuse those capabilities in the next build. The site is therefore both Calder Wong’s professional portfolio and a working public example of a scaffold that could help agents reason responsibly about other people’s experience over time.

## What’s included

- An overview connecting knowledge, experience, and reusable wisdom in a compounding flywheel.
- A character-sheet style dossier with linked skills, capabilities, evidence, and current work.
- A complete, filterable Skill Codex and Hapa ecosystem inventory.
- An architecture timeline, build journal, and public-safe evidence stories for nodes and skills.
- A Second Brain knowledge dashboard and searchable public media catalog.
- Structured discovery resources for conventional crawlers and agent-based research.

## Evidence and privacy boundaries

This is a public-safe projection, not a data dump. It deliberately distinguishes production experience, prototype work, and derived evidence metrics. It does not publish raw conversations, private notes, private media history, credentials, or local system paths. Counts and associations are useful context, not employer ratings, billing data, or claims of production usage.
