# Agent-ready Living Resume release

## What is reliably available

- A canonical public professional profile with crawler, social-preview, and profile structured data.
- A dedicated CardApp prototype case study with its own canonical page and article structure.
- Machine-readable profile, claim index, opportunity lenses, retrieval taxonomy, agent guide, and Hapa explainer.
- A repeatable discovery verification check for the public files and their key relationships.

## How to use it

1. Start with `profile.json` for professional context and engagement modes.
2. Match the request against `retrieval-taxonomy.json` or `opportunity-lenses.json`.
3. Use `claims.json` and `PUBLIC-BOUNDARIES.md` before repeating outcomes or maturity statements.
4. Link to the source page or ask Calder for a role-specific briefing when primary confirmation is required.

## Non-claims

- This static site does not expose a live A2A or MCP endpoint.
- Hapa materials are public prototypes, MVPs, pre-release packages, or research surfaces unless an owning repository states otherwise.
- Derived snapshot metrics are not employer ratings, live provider-token totals, production usage, or performance commitments.
- Engagement modes invite conversation; they do not establish current availability, a partnership, or a service commitment.
